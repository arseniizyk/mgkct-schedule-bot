# MGKCT Schedule Bot

[![Go CI](https://github.com/arseniizyk/mgkct-schedule-bot/actions/workflows/go.yml/badge.svg)](https://github.com/arseniizyk/mgkct-schedule-bot/actions/workflows/go.yml)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

**Русский** | [English](README-en.md)

Telegram-бот для удобного просмотра расписания Минского государственного колледжа цифровых технологий (МГКЦТ) для студентов и преподавателей.

Легковесный монолит на Go (Single Binary) со встроенной базой данных **SQLite (WAL)**, умным парсингом и автоматическими уведомлениями об изменениях.

---

## ✨ Возможности

- 📅 **Расписание для групп и преподавателей:**
  - Просмотр на день с быстрой навигацией (◀️ / ▶️);
  - Просмотр на неделю с переключением между доступными неделями (◀️ Предыдущая / Следующая ▶️);
  - Поддержка второй смены (автоматическое определение сдвига пар);
  - Интерактивный поиск расписания преподавателя по фамилии.
- ⏰ **Расписание звонков:** актуальное единое расписание пар для всех учебных дней.
- ⚡ **Умный опрос сайта (Smart Dynamic Polling):**
  - **Турбо-режим (Пт 12:00 — Сб утро):** частый опрос (каждые 25с) до момента публикации новой недели;
  - **Штатный режим:** опрос 1 раз в минуту в дневное время;
  - **Ночной режим / воскресенье:** опрос раз в 20 минут для экономии ресурсов.
- 🔔 **Уведомления без спама:**
  - Оповещение о публикации расписания на новую неделю (ровно 1 раз);
  - Персональные уведомления об изменениях в парах/аудиториях только при реальных правках;
  - Встроенный Rate Limiter (25 сообщений/сек) для защиты от блокировок Telegram API.
- 💾 **Встроенная база данных:** чистый Go SQLite (`modernc.org/sqlite`) в WAL-режиме, не требующий внешних СУБД, CGO или Docker.

## 🚀 Быстрый старт

### Вариант 1: Локальный запуск (без Docker)

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/arseniizyk/mgkct-schedule-bot.git
   cd mgkct-schedule-bot
   ```

2. **Создать конфигурационный файл:**
   ```bash
   cp configs/.env.example configs/.env
   ```
   Укажите ваш токен бота в `configs/.env`:
   ```env
   BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
   ```

3. **Запустить:**
   ```bash
   task run
   # или напрямую:
   go run ./cmd/bot
   ```

---

### Вариант 2: Запуск через Docker Compose

```bash
task up
# или:
docker compose --env-file=./configs/.env up --build -d
```

Остановка:
```bash
task down
```

---

### Вариант 3: Бесплатный деплой (Koyeb / Render / Fly.io / VPS)

Благодаря архитектуре монолита с чистым Go SQLite проект упаковывается в минимальный Docker-образ (<30 МБ):
- Порт Healthcheck: `8081` (`GET /healthz`);
- Том для хранения БД: `/app/data` (файл `/app/data/bot.db`).

## ⚙️ Переменные окружения

Основные параметры задаются в `configs/.env` или переменных окружения системы:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `ENV` | `dev` | Режим работы (`dev` или `prod`) |
| `BOT_TOKEN` | — | Токен бота от [@BotFather](https://t.me/BotFather) (также поддерживается `TELEGRAM_TOKEN`) |
| `BOT_HEALTH_PORT` | `8081` | Порт HTTP-сервера (`/healthz`, REST API и WebApp) |
| `BOT_WEB_APP_URL` | — | Публичный HTTPS URL для Telegram Mini App |
| `DB_PATH` | `bot.db` | Путь к файлу базы данных SQLite |
| `SCRAPER_INTERVAL` | `1m` | Стандартный интервал опроса сайта |
| `SCRAPER_PEAK_INTERVAL` | `25s` | Турбо-интервал в Пт-Сб до нахождения новой недели |
| `SCRAPER_NIGHT_INTERVAL` | `20m` | Ночной интервал опроса (22:00 - 08:00 и в воскресенье) |

## 🏛 Архитектура

```
┌────────────────────────────────────────────────────────┐
│               mgkct-bot (Single Binary)                │
│                                                        │
│  ┌──────────────────┐           ┌───────────────────┐  │
│  │  Scraper Engine  │ ─(Chan)─► │  Telegram Engine  │  │
│  │ (Smart Polling)  │           │  (Telebot + Rate) │  │
│  └────────┬─────────┘           └─────────┬─────────┘  │
│           │                               │            │
│           │                     ┌─────────┴─────────┐  │
│           │                     │  HTTP / WebApp    │  │
│           │                     │  (Mini App + API) │  │
│           │                     └─────────┬─────────┘  │
│           │                               │            │
│           └───────────────┬───────────────┘            │
│                           ▼                            │
│              Встроенная SQLite (WAL-mode)              │
└────────────────────────────────────────────────────────┘
```

- **Кодовая база:** единый Go-модуль без protobuf/gRPC и брокеров NATS.
- **Telegram Mini App (TMA):** встроенное адаптивное веб-приложение для наглядного просмотра расписания звонков, групп и преподавателей с поддержкой тем Telegram и быстрой навигации.
- **Миграции:** встроенные через `embed` goose-миграции, применяются автоматически при старте.
- **Graceful Shutdown:** корректное завершение long-polling сессии telebot, остановка скрапера, закрытие HTTP сервера и соединений SQLite по сигналам `SIGINT`/`SIGTERM`.
